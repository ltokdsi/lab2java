## Задание 1.

### Задача 1.3: Имена
#### Текст задачи
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество (например "Иванов Иван Иванович"). Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.
Необходимо создать следующие имена:
Клеопатра
Пушкин Александр Сергеевич
Маяковский Владимир
Обратите внимание, что при выводе на экран, не заданные параметры никак не участвуют в образовании строки.
#### Алгоритм решения
Создается класс `Name` с тремя строковыми полями (`surname`, `firstName`, `patronymic`). В переопределенном методе `toString()` создается объект `StringBuilder`. Выполняется проверка каждого поля на `null` и на пустоту строки (состоящую только из пробелов). В итоговую строку добавляются только те параметры, которые были реально заданы, а лишние пробелы отсекаются с помощью метода `trim()`.

## Задание 2.

### Задача 2.2: Человек с именем
#### Текст задачи
Объедините сущности Человек из задачи 1.2 и Имя из задачи 1.3 таким образом, чтобы имя человека задавалось с использованием сущности 1.3, а не строки.
Необходимо объединить ранее созданные объекты имен и людей, с получением:
Человека с Именем Клеопатра и ростом 152
Человека с Именем Пушкин Александр Сергеевичи ростом 167
Человека с Именем Маяковский Владимир и ростом 189
#### Алгоритм решения
В классе `Person` поле имени, которое раньше было обычной строкой, заменяется на объект типа `Name` (реализуется агрегация). В конструкторе инициализируется поле класса `Name` и числовое поле роста `height`. При приведении человека к строке в методе `toString()` вызывается внутренний метод `toString()` объекта `Name`, к результату которого через запятую конкатенируется информация о росте.

### Задача 2.3: Человек с родителем
#### Текст задачи
Измените сущность Человек из задачи 2.2 добавив ему возможность задавать третий параметр: Отец, где Отец это тоже Человек. При приведении человека к строковой форме необходимо проверить параметры имени, и в зависимости от ситуации выполнить одно из следующих действий:
• Если у данного человека нет фамилии, и есть отец, у которого фамилия задана, то фамилию необходимо сделать такой же как у отца.
• Если у данного человека нет отчества, а у отца есть имя, то необходимо задать отчество как имя отца с добавлением суффикса "ович".
Затем необходимо выполнить следующие задачи:
1. Создать людей: Чудова Ивана, Чудова Петра, Бориса
2. Сделать Ивана отцом Петра, а Петра отцом Бориса
3. Вывести на экран строковое представление всех троих людей.
При желании можно попытаться реализовать систему в более полном виде: предусмотреть разные виды суффиксов отчества в зависимости от окончания имени, а также предусмотреть возможность задавать пол человека и менять суффикс отчества в зависимости от пола.
#### Алгоритм решения
В класс `Person` добавляется поле `father` (ссылка на другой объект `Person`) и соответствующий перегруженный конструктор. В методе `toString()` проверяется наличие ссылки на отца. Если она существует, локальным переменным присваиваются фамилия отца (если своя отсутствует) и формируется отчество (к имени отца прибавляется строка `"ович"`). На базе обновленных данных формируется новый временный объект `Name`, который и преобразуется в итоговую строку для вывода.

## Задание 3.

### Задача 3.2: Ломаная
#### Текст задачи
Создайте сущность Ломаная, которая будет представлять собой ломаную линию (см. пример на рис.1). Ломаная линия представляет собой набор следующих характеристик:
Имеет массив Точек (из задачи 1.1), через которые линия проходит.
Может быть приведена к строковой форме вида "Линия [Т1, T2,...,TN]", где это результат приведения к строке Точки с номером №.
Необходимо выполнить следующие задачи:
Создать первую Ломаную, проходящую через точки {1;5}, {2;8}, {5;3}
Создайте вторую Ломаную, чья первая и последняя Точка совпадает с таковыми у первой Ломаной, но в качестве середины имеет точки: {2;-5}, {4;-8}
Сдвиньте начало первой Ломаной таким образом, чтобы одновременно сдвинулось начало второй Ломаной.
#### Алгоритм решения
Реализуется вспомогательный класс `Point`. В классе `Polyline` объявляется поле типа `List<Point>` (список точек). В конструктор передается набор начальных точек, которые сохраняются в этот список. Метод `toString()` обращается к стандартному строковому представлению коллекции `List` (которое автоматически вызывает метод `toString()` у каждой точки внутри массива) и добавляет спереди префикс `"Линия "`.

## Задание 4. 

### Задача 4.9: Создаем Ломаную
#### Текст задачи
Измените сущность Ломаная из задачи 1.3.2. Новые требования включают:
Ломаная может быть создана без указания каких-либо параметров
Ломаная может быть создана с указанием некоторого набора Точек
#### Алгоритм решения
В классе `Polyline` реализуется перегрузка конструкторов. Первый конструктор не принимает аргументов и инициализирует пустой список (например, `this.points = new ArrayList<>()`). Второй конструктор использует механизм аргументов переменной длины (`Point... pts`), преобразует неограниченное число переданных точек в список с помощью `Arrays.asList(pts)` и сохраняет их в состояние объекта.

## Задание 5. 

### Задача 5.7: Длина Ломаной
#### Текст задачи
Длина Ломаной. Измените сущность Ломаная из задачи 4.9. Новые требования включают:
В любой момент к имеющимся Точкам можно добавить новые Точки (добавляется либо массив, либо просто перечень Точек, что приводит к получению нового массива, содержащего как старые, так и новые значения).
Может возвращать общую длину Ломаной.
Необходимо выполнить следующие задачи:
1. Создать Ломаную, проходящую через точки {1;5}, {2;8}, {5;3}
2. Вывести на экран её длину
3. Добавить (к ранее созданной Ломаной) точки {5;15}, {8;10}
4. Снова вывести на экран длину Ломаной
#### Алгоритм решения
Добавляется метод `addPoints(Point... pts)`, который за счет поддержки аргументов переменной длины способен принимать как перечень точек через запятую, так и целый массив. Точки присоединяются в конец существующего списка через `addAll()`. Для вычисления длины реализуется метод `getLength()`. В нем запускается цикл `for` от `0` до `points.size() - 1`. На каждой итерации с помощью математических функций (`Math.sqrt` и `Math.pow`) по теореме Пифагора вычисляется евклидово расстояние между текущей и следующей точкой. Эти отрезки суммируются в общую переменную, которая возвращается как результат.
